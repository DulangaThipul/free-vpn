## ⚡ Overview

**LEGION Free VPN** is a modern, high-speed, and serverless VPN delivery system engineered to distribute customized **Trojan** and **VLESS** configurations across Sri Lankan telecom networks (Dialog, Airtel, Hutch). 

Operating on a distributed architecture, it bridges frontend verification flows with a **Singapore 1Gbps Dedicated Node**, injecting dynamic SNI parameters on-the-fly to guarantee uninterrupted connectivity for specialized ISP packages.
